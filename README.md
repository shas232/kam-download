# Kam

Kam is an AI assistant for Indian CA firms: it reads the client's papers, prepares the working
(GST, TDS, bank reconciliation, ITR, notices) and drafts the messages, and the CA checks and signs.

## Download (always the latest version)

| Computer | Download |
|---|---|
| **Windows** (64-bit) | [Kam for Windows](https://kam-cloud.shashin-bhaskar.workers.dev/download/windows) |
| **Mac** (Apple silicon: M1 and later) | [Kam for Mac](https://kam-cloud.shashin-bhaskar.workers.dev/download/mac) |

Kam updates itself after that.

## Installing

- **Windows:** open the downloaded file. If Windows shows "Windows protected your PC",
  click **More info → Run anyway**.
- **Mac:** open the downloaded file and drag Kam to Applications. The first time, right-click
  Kam in Applications and choose **Open**, then **Open** again.

Then sign in with your Google account.
